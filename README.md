\# 🚀 Overview



Finance AI is an intelligent personal finance platform designed to help users make smarter financial decisions using AI-powered analytics.



The platform enables users to:



\- 💳 Track Income \& Expenses

\- 📊 Visualize Financial Analytics

\- 💰 Manage Budgets

\- 🎯 Create Savings Goals

\- 📈 Investment Recommendations

\- 🤖 AI Financial Assistant

\- 📑 Generate Reports

\- 📤 Export Reports

\- 🔔 Smart Notifications

\- 📱 Responsive Dashboard

\# ⚙️ Installation



\## Clone Repository



```bash

git clone https://github.com/Rudra-1612/Finance-AI.git

```



\## Navigate



```bash

cd Finance-AI

```



\## Backend



```bash

mvn clean install

mvn spring-boot:run

```



\## Frontend



Open the frontend using your preferred development server.
